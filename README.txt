GLP-1 12-Week Companion PWA

FILES
- index.html: the app
- manifest.webmanifest: iPhone/PWA install metadata
- sw.js: offline cache/service worker
- icon-192.png / icon-512.png: app icons

HOW TO USE ON IPHONE
1. Host this folder on any HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the hosted URL in Safari on the iPhone.
3. Tap Share > Add to Home Screen.
4. Launch GLP-1 Plan from the Home Screen.

DATA PRIVACY
Daily check-in selections and weight entries are stored in browser localStorage on the device/browser profile. There is no backend or account system in this version.

PROGRAM
- Start date: Thursday, August 20, 2026
- Duration: 12 weeks through Sunday, November 8, 2026
- Thursday-night tirzepatide injection reminder
- Strength A/B, running, recovery, nutrition targets, symptom-adaptive guidance

IMPORTANT
This is a planning/tracking aid, not medical software. Medication dosing and medical decisions should follow the prescribing clinician's instructions.
